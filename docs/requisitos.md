🏠 Página Principal:

El botón «Borrar» aparece si el usuario conectado donó el peluche.
El botón Borrar elimina el libro de la base de datos.
El botón «Editar» aparece si el usuario conectado donó el peluche.
El botón Editar redirecciona a la página Editar.
La página principal debe decir «Bienvenido {{ nombre de usuario }}»
👁️ El enlace «Ver» redirecciona a la página individual de cada peluche.
➕ Crear una nueva donación:

Esta pantalla solo es accesada si el usuario inició sesión
Validar que los campos no estén vacíos
✏️ Editar una donación:

Esta pantalla solo es accesada si el usuario inició sesión
Mismas validaciones que la creación
Los campos están pre-populados con la información actual de ese peluche desde la base de datos.
🎨 HTML y CSS deben reflejar la estructura como mínimo al 75% de precisión.
⭐ Requisitos para BONUS
➡️ El usuario es capaz de Adoptar un peluche
➡️ Se muestra cuáles de los peluches están Adoptados
➡️ El nombre del peluche debe ser único
➡️ En la edición, implementar las mismas validaciones. El nombre del peluche puede ser el mismo que en antes
➡️ En los detalles del peluche se muestra quién lo adoptó (en caso de aplicar)
➡️ En los detalles del peluche se muestra cuántas personas han ingresado a esa página, es decir cada visita a esa página específica debe de aumentar el contador de vistas de ese peluche en 1.
